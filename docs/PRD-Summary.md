# PRD Summary

Karsenz currently coordinates vehicle pickups through WhatsApp, which makes future-dated bookings easy to miss and prevents managers from seeing assignment, progress, proof and handover status in one place.

The MVP must make the system of record a schedule-first operations platform:

- Customer service creates current-day or future pickup bookings.
- Dispatchers view demand, driver availability and unassigned work.
- Drivers execute a guided mobile workflow from acceptance to branch arrival.
- Vehicle condition, customer acknowledgement and images are captured before pickup completion.
- Workshop staff must accept handover before a booking can become completed.
- Managers see live operational KPIs and exportable reports.

The PRD emphasizes these acceptance themes:

- Future bookings must appear on calendars and chronological lists, with due-today and overdue visibility.
- Assignment must check driver availability, overlapping jobs and branch capacity.
- Every material event must be statused, timestamped and auditable.
- WhatsApp is a communication channel only; it is not the source of truth.
- MVP excludes automatic route optimization, customer self-service and continuous GPS tracking.
